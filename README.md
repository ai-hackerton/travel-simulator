## Travel Simulator 가관

가상 환경에서 여행을 체험할 수 있는 웹 기반 시뮬레이션 서비스입니다.
사용자는 여행 기간, 지역, 시작 지점을 설정한 뒤, 실제 관광 데이터를 기반으로 여행 경로를 선택하며 진행할 수 있습니다.

[![Watch the demo](https://img.youtube.com/vi/y8VL-dY4LQ8/maxresdefault.jpg)](https://youtu.be/y8VL-dY4LQ8)

지도 기반 UI와 관광 API를 결합하여 지역 선택과 이동 흐름을 직관적으로 구성했고,
관광지 이미지, 상세 정보, 주변 환경(지도/로드뷰)을 함께 제공하여 실제 여행과 유사한 경험을 목표로 했습니다.

### 주요 기능

* 지역 및 시작 지점 선택 (지도 기반 인터랙션)
* 여행 경로 단계별 진행 (이동 → 장소 선택 → 정보 확인)
* 관광공사 API 기반 장소/이미지/정보 제공
* 지도 및 로드뷰를 활용한 공간 체험
* 사용자별 시뮬레이션 기록 저장

### 기술 스택

* Next.js, React
* Zustand (상태 관리)
* Tailwind CSS
* Naver Map API, D3
* Firebase
* Tour API (한국관광공사)

### 실행 흐름

1. 사용자 정보 및 여행 설정 입력
2. 여행 시작 지점 선택
3. 단계별로 관광지 탐색 및 이동
4. 지도/이미지/정보를 통해 가상 여행 경험 제공
